### 🚀 Featured Project

<table>
<tr>
<td width="100%">

**⚽ [EPL Predictor](https://github.com/cem-oral/EPL-Predictor)** — *Graduation Project*

A machine learning pipeline that predicts Premier League match outcomes using time-series feature engineering (Dynamic ELO, Form, Head-to-Head, xG) on 9,300+ matches dating back to 2000.

- 🧠 Soft-Voting Ensemble combining **XGBoost, CatBoost, LightGBM, Random Forest & Gradient Boosting**
- 📈 Full-season simulation engine (380 matches) using **Poisson Distribution** and in-game momentum modeling
- ⚙️ Deployed as a **FastAPI** REST microservice
- 🌐 Full-stack architecture with **Spring Boot** backend and **React** frontend
